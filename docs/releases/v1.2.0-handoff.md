## Implemented vertical slice

```text
Event → risk/detection → N:1 incident correlation → asset + MITRE + IP reputation
      → grounded Copilot → simulated containment → timeline + audit → report
```

The real AbuseIPDB adapter is deployment-optional. If its server-only secret is
absent or the provider is unavailable, the UI says so and local evidence remains
usable. `frontend/vercel.json` makes the BFF deployable to Vercel, but the verified
live frontend remains Render to avoid requiring another provider for the portfolio.
