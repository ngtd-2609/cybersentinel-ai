# CyberSentinel AI v1.1.0

Release date: 2026-09-05

CyberSentinel AI v1.1.0 is the first complete public portfolio release. It brings
the data/ML pipeline, secure API, SOC interface, real-time operations, AI
reliability, and a real hosted demo into one verified release.

## Highlights

- Public HTTPS portfolio on Render with Neon PostgreSQL and safe one-click demo.
- Next.js SOC interface covering Dashboard, Events, Incidents, Threat Intel,
  Copilot, Model Monitor, Monitoring, Reports, and RBAC administration.
- FastAPI detection/incident platform with PostgreSQL migrations, Redis quotas,
  batch ingestion, dead-letter recovery, SSE, audit logs, and role enforcement.
- Leakage-aware CIC-IDS2017 model evaluation, DVC/MLflow provenance, lifecycle
  promotion gates, drift reports, and analyst TP/FP feedback.
- Grounded SOC Copilot with evidence preservation, prompt-injection defense,
  bounded retry/circuit breaker, and deterministic sourced fallback.
- Prometheus/Grafana/Loki observability, k6 SLO, backup/restore drill, immutable
  deployment/rollback tooling, and multi-layer security CI.
- One-command local portfolio demo through `./scripts/start-demo.sh`.
- GitHub-focused README, screenshots, security policy, contributing guide, final
  handoff, and machine-readable release state.

## Verification

- 179 Python tests collected; full Pytest and Ruff pass in CI.
- Full Next.js lint, production build, and Playwright E2E pass.
- Empty PostgreSQL migration, downgrade/re-upgrade, schema, and CRUD pass.
- Dependency audits, Bandit, Trivy, Redis integration, and OWASP ZAP pass.
- PostgreSQL checksum backup and disposable restore pass.
- Public no-mock journey passes Login → Dashboard → Events → Incidents → Threat
  Intel → Copilot → Reports.

## Deployment

- Web: <https://cybersentinel-web-ppae.onrender.com>
- API readiness: <https://cybersentinel-api-hrl8.onrender.com/ready>
- Database: Neon PostgreSQL

The free services may cold start after inactivity. The UI polls readiness and
explains the delay. Provider secrets are not stored in Git.

## Known limitations

- CIC-IDS2017 is dated; locked-test recall under temporal shift is intentionally
  documented and would require representative retraining before operational use.
- The hosted free tier is for portfolio evaluation, not uptime-critical traffic.
- Copilot output is decision support and requires human review.
- No open-source license has been declared.
