# CyberSentinel AI v1.2.0

Release date: 2026-09-06

This release completes the public SOC investigation vertical slice while keeping
the application safe and affordable as a portfolio deployment.

## Highlights

- Added persisted assets and linked them to detections and affected incidents.
- Expanded incidents into cases with stable display IDs, priority, assignment,
  tags, resolution metadata, affected assets and related detection evidence.
- Added combined, URL-backed incident filters and a coherent six-detection attack
  scenario on `prod-web-01`.
- Added an AbuseIPDB provider adapter with PostgreSQL caching, timeout handling
  and a graceful no-key/provider-down state.
- Added persisted simulated containment actions that always write timeline and
  audit evidence without modifying an external system.
- Grounded incident Copilot requests with the complete persisted case context.
- Added a Vercel frontend manifest while retaining Render + Neon as the verified
  live, near-zero-cost portfolio deployment.
