# CyberSentinel AI v1.1.1

Release date: 2026-09-06

This portfolio patch makes the hosted experience safe and usable for first-time
reviewers without changing the completed Phase G–M scope.

## Highlights

- Visitors can create a Viewer account and are signed in automatically.
- Registration is per-IP rate-limited, capacity-bounded, and cannot grant a
  privileged role.
- The one-click demo account is now read-only and every API restart restores the
  canonical three-incident demo state.
- English/Vietnamese switching persists on the device.
- Mobile navigation, event search, notifications, settings, incident links, and
  Copilot entry points now work.
- Dashboard and model-monitoring labels no longer present static mock values as
  live production telemetry.
